**Prompt, Confirm, Alert

Estas son maneras en JavaScript para interactuar con el usuario son poco utilizadas por que interrumpen el flujo de ejecución del programa 

`alert('Bienvenido + nombre')` -> permite enviar un mensaje o aviso a un usuario.

`confirm('Desea continuar ?')` -> Permite enviarle un mensaje para confirmar una accion y retorna un valor `boolean` 

`prompt('Introduzca su nombre')` -> Permite al usuario introducir datos 


**Array


Los arrayen muchos lenguajes son colecciones de datos de un mismo tipo en JavaScript es mas flexible por que puedes almacenar desde números enteros hasta colecciones dentro de otras y funciones

Existen dos maneras para iniciar los arreglos puedes utilizar ambas 

Ejemplo 1:
`let juegos = ['Zelda','Mario','Metroid','Donkey Kong '];`

Ejemplo 2:

`let nombre = new Array('Raidy','Raul','Rosa');`



**Métodos** (Para operar los array)

`Array.Push('GTA V')` -> Agrega un elemento nuevo al final de la colección
y retorna la nueva longitud del arreglo.

`Array.unshift('MLB 2026')` -> Agrega un elemento nuevo al inicio del arreglo y retorna
la nueva longitud.

`Array.pop()` -> Elimina un elemento y retorna un string con el elemento eliminado del arreglo(El ultimo elemento)

`Array.forEach((Array) => {`console.log(Array);`})` -> Se utiliza para iterar entre los elementos de una colección tienes tres opciones imprimir `Elements`, `Array`, `Index`.
